# Практическая работа № 5

Выполнил: Цапков Н. В., группа 09с41.

## Описание
Программа обрабатывает анкеты, проверяет данные
и выводит результаты со статистикой.

## Файлы
- main.py — запуск программы
- validators.py — проверка данных
- storage.py — чтение и сохранение файлов
- report.py — вывод результатов
- anketa.txt — входные данные
- test_checks.py — тесты

## Запуск
python main.py

## Проверка
python -m pytest -q
